# 2026-06-04 工作日志

## 匿名用户汉堡菜单"退出"按钮卡死问题修复

### 根因分析
匿名用户点击"退出" → 调用 `logout()` → `logout()` 调用 `loadPublicBooks()` → **快速多次点击时 `loadPublicBooks()` 被并发调用多次** → API 请求堆积 + DOM 重复渲染 → 页面卡死。

`logout()` 本身也没有防重复点击保护，多点几次就会触发并发。

### 修复内容

1. **汉堡菜单底部按钮动态切换**：
   - 添加 `updateProfileCardLogoutBtn()` 函数
   - 判断条件：`state.currentUser && state.currentUser.phone`（不是仅 `state.currentUser`）
   - 已有手机号 → 显示"退出"，点击退出
   - 匿名用户（无 phone）→ 显示"注册"，点击打开注册弹窗
   - 在 `checkLogin()`、`onLoginSuccess()`、`logout()` 末尾调用此函数

2. **`logout()` 加防重复点击锁**：`_logoutLock`

3. **`loadPublicBooks()` / `loadBooks()` 加并发锁**：`_loadPublicBooksLock` / `_loadBooksLock` + `finally` 释放

4. **`doLogin()` / `doRegister()` 加防重复提交锁**：所有分支释放

### BugFix：仍显示退出
条件 `state.currentUser` 对匿名用户也为 true（有 user 对象但 phone 为 null），改为 `state.currentUser && state.currentUser.phone`
